# AI Development Disclosure

## Development Approach

Terminal File Manager was developed using an AI-assisted vibe-coding workflow. AI tools contributed to code generation, implementation, debugging, and iterative development based on project requirements and instructions.

## Human Involvement

The project maintainer guides the development process, defines requirements, evaluates results, and is responsible for the ongoing maintenance of the project.

## Transparency

This disclosure documents the use of AI during development. It does not imply that every line of code was generated by AI or that AI-generated output is automatically correct.
